# File Manager — 你需要安装的软件

按下面顺序操作即可。装完一项可在 `[ ]` 里打勾（在编辑器里把 `[ ]` 改成 `[x]`）。

---

## 清单总览

| 序号 | 软件 | 是否必须 | 用途 |
|------|------|----------|------|
| 1 | Node.js 20+ | 必须 | 前端与 Tauri 命令行 |
| 2 | Rust（rustup） | 必须 | Tauri 后端编译 |
| 3 | Visual Studio Build Tools（C++） | 必须 | Windows 上编译 Rust |
| 4 | 本项目 `npm install` | 必须 | 安装前端依赖 |
| 5 | WebView2 | 通常已有 | Tauri 显示界面（Win10/11 多数已自带） |

---

## 1. Node.js（若已安装可跳过）

**检查是否已有：**

```powershell
node -v
npm -v
```

能显示版本号（建议 Node **20** 或更高）即可跳过。

**若没有，请安装：**

- 官网：https://nodejs.org/  
- 选 **LTS** 版本，一路下一步即可。

---

## 2. Rust（rustup）

**检查是否已有：**

```powershell
rustc --version
cargo --version
```

两条都能显示版本即表示已装好。

**若没有，请安装：**

1. 打开：https://rustup.rs/  
2. 下载并运行 **rustup-init.exe**（64-bit）。  
3. 安装程序里直接按提示选默认（输入 `1` 回车即可）。  
4. **安装结束后关闭当前终端，再新开一个 PowerShell**，执行：

```powershell
rustup default stable
rustc --version
```

**若下载很慢或超时**，可多试几次 `rustup default stable`，或参考国内镜像：https://rsproxy.cn  

---

## 3. Visual Studio Build Tools（C++）— 很重要

Rust 在 Windows 上需要 **MSVC 编译器**。没装这一项时，`npm run tauri dev` 常会报错。

**请安装：**

1. 打开：https://visualstudio.microsoft.com/visual-cpp-build-tools/  
2. 下载 **Build Tools for Visual Studio**。  
3. 安装时在「工作负载」里勾选：  
   - **使用 C++ 的桌面开发**（Desktop development with C++）  
4. 右侧「安装详细信息」里至少包含（一般默认就有）：  
   - MSVC v143（或更新）  
   - Windows 10/11 SDK  

装完后**建议重启电脑**（或至少新开终端）。

**检查（可选）：** 安装完成后没有单独命令行检查项，能成功跑通下面第 5 步即表示 OK。

---

## 4. 安装本项目依赖

在 PowerShell 中：

```powershell
cd "d:\File maneger"
```

若之前 `npm install` 因缓存权限失败，可先执行：

```powershell
set NPM_CONFIG_CACHE=%CD%\.npm-cache
```

再执行：

```powershell
npm install
```

看到 `added ... packages` 且无报错即可。

---

## 5. 启动开发版（验证是否全部装好）

仍在项目目录：

```powershell
npm run tauri dev
```

- **第一次**会下载并编译大量 Rust 依赖，可能 **5～20 分钟**，请耐心等待。  
- 成功后会自动弹出 **「File Manager — 文件整理」** 窗口。  
- 可点「桌面 / 下载 / 文档」或「选择目录」→「开始扫描」试用。

**若失败，常见原因：**

| 现象 | 处理 |
|------|------|
| 找不到 `rustc` / `cargo` | 重做第 2 步，并**新开终端** |
| 提示 `link.exe`、MSVC、LNK 相关错误 | 重做第 3 步（C++ Build Tools） |
| 网络超时下载 Rust 组件 | 多试 `rustup default stable` 或配置 rsproxy 镜像 |
| 端口 1420 被占用 | 关闭占用该端口的程序后重试 |

---

## 6. WebView2（一般不用你管）

Tauri 在 Windows 上依赖 **Microsoft Edge WebView2**。  
Windows 10/11 多数系统已自带；若启动时提示缺少 WebView2：

- 下载：https://developer.microsoft.com/microsoft-edge/webview2/

---

## 全部装好后 — 常用命令

```powershell
cd "d:\File maneger"

# 开发模式（改代码会自动刷新）
npm run tauri dev

# 打包成安装程序（需要第 1～3 步都已就绪）
npm run tauri build
```

打包结果目录：`src-tauri\target\release\bundle\`

---

## 平时怎么启动

| 你怎么用 | 怎么做 |
|----------|--------|
| **开发 / 自己改代码** | 打开终端 → `cd "d:\File maneger"` → `npm run tauri dev` |
| **已经打包安装过** | 从开始菜单打开 **File Manager**，或在 [GitHub Releases](https://github.com/crazyjackab/cp/releases) 下载最新 `File Manager_x.x.x_x64-setup.exe` |
| **使用仓库内安装包** | 运行 `updates\File Manager_0.2.0_x64-setup.exe`（当前最新版） |
| **自己打包** | 在项目目录执行 `npm run tauri build`，到 `src-tauri\target\release\bundle\nsis\` 里安装 |

## 推荐自检顺序（打勾用）

- [ ] `node -v`、`npm -v` 正常  
- [ ] `rustc --version`、`cargo --version` 正常  
- [ ] 已安装 Visual Studio Build Tools（含 C++ 桌面开发）  
- [ ] 在项目目录执行过 `npm install`  
- [ ] `npm run tauri dev` 能打开窗口  

---

## 你不需要安装的

- Python、Java、Docker（本项目不用）  
- 完整版 Visual Studio（若只装 Build Tools 即可）  
- 额外数据库（当前版本数据都在本机扫描，无服务端）

---

有问题时，把**完整报错**从终端复制发出来即可排查。
