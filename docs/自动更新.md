# 自动更新

File Manager 使用 Tauri 官方 [Updater 插件](https://v2.tauri.app/plugin/updater/) 实现自动检查、下载与安装更新。

## 前置条件

- 更新端点必须是 **HTTPS**
- 安装包必须使用 **私钥签名**（公钥已写入 `src-tauri/tauri.conf.json`）
- 用户安装的是 **正式打包版本**（`npm run tauri dev` 开发模式不支持更新）

## 一次性配置

### 1. 生成签名密钥（已完成）

密钥位于项目根目录 `.tauri/`（已加入 `.gitignore`，请勿提交私钥）：

- 私钥：`.tauri/file-manager.key`（密码：`file-manager`）
- 公钥：`.tauri/file-manager.key.pub`（内容已配置到 `tauri.conf.json`）

若丢失私钥，将无法向已安装用户推送更新，请务必妥善备份。

### 2. 配置更新端点

已配置为公开仓库 [crazyjackab/cp](https://github.com/crazyjackab/cp)：

```json
"endpoints": [
  "https://github.com/crazyjackab/cp/releases/latest/download/latest.json"
]
```

仓库已公开，客户端可正常匿名拉取 Release 中的 `latest.json` 和安装包。

### 3. 应用内行为

- **设置 → 更新**：手动检查更新、查看版本、下载安装
- **启动时自动检查**：默认开启，发现新版本会在主界面顶部显示横幅
- Windows 安装模式为 `passive`（小窗进度条，无需用户逐步点击）

## 发布新版本流程

### 1. bump 版本号

同步修改：

- `package.json` 的 `version`
- `src-tauri/Cargo.toml` 的 `version`
- `src-tauri/tauri.conf.json` 的 `version`

### 2. 设置签名环境变量并构建

PowerShell：

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY_PATH = "D:\File maneger\.tauri\file-manager.key"
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "file-manager"
npm run tauri build
```

构建完成后，除常规安装包外，还会生成 **`.sig` 签名文件**（因已启用 `createUpdaterArtifacts`）。

Windows 产物示例：

- `src-tauri/target/release/bundle/nsis/File Manager_x.x.x_x64-setup.exe`
- `src-tauri/target/release/bundle/nsis/File Manager_x.x.x_x64-setup.exe.sig`

### 3. 编写 latest.json

参考 `updates/latest.json.example`，填写：

| 字段 | 说明 |
|------|------|
| `version` | 新版本号（SemVer） |
| `notes` | 更新说明（可选） |
| `platforms.windows-x86_64.url` | 安装包 HTTPS 下载地址 |
| `platforms.windows-x86_64.signature` | 对应 `.sig` 文件的**完整文本内容** |

### 4. 发布到 GitHub Releases（推荐）

1. 在 GitHub 创建 Release，标签如 `v0.2.0`
2. 上传 `File Manager_x.x.x_x64-setup.exe`
3. 上传 `latest.json`（文件名必须为 `latest.json`）
4. 确保 `latest.json` 中的 `url` 指向该 Release 中的安装包

也可使用脚本辅助生成 `latest.json` 骨架：

```powershell
.\scripts\publish-update.ps1 -Version 0.2.0 -SetupPath "src-tauri\target\release\bundle\nsis\File Manager_0.2.0_x64-setup.exe"
```

## 测试建议

1. 安装当前版本（如 v0.1.0）
2. 发布 v0.2.0 到 GitHub Releases 并上传 `latest.json`
3. 打开已安装应用 → **设置 → 检查更新**，或重启应用触发自动检查
4. 确认能下载、安装并自动重启

## 常见问题

**检查更新报 404**  
端点 URL 或 GitHub 仓库路径未配置正确，或 Release 中缺少 `latest.json`。

**开发模式无法检查**  
属正常现象，请用 `tauri build` 产出的安装包测试。

**签名验证失败**  
`latest.json` 中的 `signature` 与安装包不匹配，或使用了错误的私钥/公钥对。
