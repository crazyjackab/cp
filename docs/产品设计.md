# 产品设计 — 你要的「文件收纳库」

## 你想解决什么问题

1. **桌面太乱**：文件堆在桌面上，不好找。  
2. **有一个固定「存放处」**：不只想扫描电脑里原有文件夹，而是希望**把文件收进这个工具管的地方**。  
3. **按类型集中管理**：照片、视频、文档等散落在各处，希望**归到一处**，在工具里就能查看、浏览、管理。

---

## 和当前版本的区别

| | 当前已做的（Phase 0） | 你真正想要的 |
|---|----------------------|--------------|
| 角色 | 像「体检仪」：扫描某个文件夹，告诉你占了多少、有哪些类型 | 像「资料库」：文件**搬进来或归进来**，长期放在这里 |
| 桌面 | 不会动桌面上的文件 | 可从桌面/下载**收纳**进资料库，桌面变干净 |
| 查看 | 统计表、扩展名排行 | **按图片 / 视频 / 文档** 分类浏览，便于查找 |
| 入口 | 选目录 → 扫描 | 打开软件 → 直接看到自己的资料库 |

你现在截图里的「总览 + 扫描下载文件夹」仍然有用（了解哪里最乱），但会升级为资料库的**辅助功能**，而不是产品的核心。

## 产品定位（修订）

**File Manager = 本机私人文件资料库**

- 在电脑上划定一块**资料库目录**（默认在用户目录下，可改）。  
- 文件按类型进入子文件夹，并在应用内用**分类视图**浏览。  
- 从桌面、下载等位置**一键收纳**，减少桌面堆积。  
- 所有文件仍在磁盘上真实存在，可用资源管理器打开；工具负责**归类、展示、快速找**。

---

## 资料库目录结构（规划）

默认位置示例（可在设置里修改）：

```text
C:\Users\你的用户名\FileManager\资料库\
├── 收件箱\          ← 新收纳的文件先到这里（可选，再自动分类）
├── 图片\
├── 视频\
├── 文档\
├── 音频\
├── 压缩包\
├── 安装包\
└── 其他\
```

规则示例：

- `.jpg` `.png` `.heic` → **图片**  
- `.mp4` `.mkv` `.mov` → **视频**  
- `.pdf` `.docx` `.xlsx` → **文档**  
- 无法识别 → **其他**

## 核心使用流程（目标体验）

### 日常收纳

1. 打开 File Manager。  
2. 点击 **「从桌面收纳」** 或 **「收纳文件」**（多选）。  
3. 文件移动到资料库对应分类（默认**移动**，可选**复制**）。  
4. 桌面变干净；在软件里点 **图片 / 视频** 即可查看。

### 日常查看

1. 打开软件 → 左侧选 **图片** 或 **视频**。  
2. 浏览列表或缩略图，双击用系统默认程序打开。  
3. 需要时在资源管理器中显示原路径。

### 偶尔整理电脑其他位置

1. 使用 **总览** 扫描下载夹等（即你现在用的功能）。  
2. 根据统计决定要不要 **收纳进资料库**。

## 已确认的设置（2026-05）

| 项 | 值 |
|----|-----|
| 收纳方式 | **移动**（桌面文件进资料库后，桌面不再保留） |
| 资料库位置 | **`D:\FileManager\资料库\`** |

配置文件：`%APPDATA%\FileManager\config.json`
